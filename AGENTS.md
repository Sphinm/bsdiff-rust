## Cursor Cloud specific instructions

This is a Rust + Node.js native addon library (`@bsdiff-rust/node`) using NAPI-RS. It implements bsdiff/bspatch binary diff/patch algorithms. There are no external services (no databases, no HTTP servers, no Docker required for local dev).

### Key commands

All standard dev commands are in `package.json` scripts — see README.md for details. Quick reference:

| Task | Command |
|------|---------|
| Install deps | `pnpm install` |
| Build native addon (release) | `pnpm build` |
| Build native addon (debug) | `pnpm build:debug` |
| Run tests | `pnpm test` |
| Lint | `pnpm lint` |
| Format | `pnpm format` |
| Benchmark | `pnpm run bench` |

### Non-obvious caveats

- **Rust version**: The napi v3 dependencies require Rust >= 1.88. The pre-installed Rust toolchain may be too old. Run `rustup default stable` after `rustup update stable` if `pnpm build` fails with `edition2024` or version errors.
- **Test resources**: Tests require two zip files that are NOT checked into git. Fetch them before running `pnpm test`:
  ```
  pnpm test:resources
  ```
  (Downloads into `test/resources/`, skips files that are already present, and fails loudly on a truncated download. Without them `pnpm test` aborts in its `before` hook with "测试文件不存在".)
- **Rust formatting**: `rustfmt.toml` pins `tab_spaces = 4` and `max_width = 120` to match the style the sources actually use; `cargo fmt --check` is clean and is expected to stay clean. (`tab_spaces` is deliberately not 2 despite `.editorconfig`'s `indent_size = 2`, which governs JS/TS/MD/JSON/TOML only — rustfmt defaults to 4 for Rust.)
- The native `.node` binary is generated in the workspace root (e.g., `node.linux-x64-gnu.node`) and is loaded by `index.js`. You must run `pnpm build` before tests or any usage.
- **Run `pnpm build` (release) before `pnpm test`, not `pnpm build:debug`.** The suite gives each case a 10s budget; the unoptimized debug addon (~2.7 MB vs ~0.64 MB) exceeds it and the tests fail with "Timeout of 10000ms exceeded", which looks like a real failure but is only a slow artifact.
- The Rust code lives in a Cargo workspace (`core/` + `bindings/`), so `pnpm build` passes `--manifest-path bindings/node/Cargo.toml` to napi — the CLI cannot pick a crate from the virtual workspace root on its own. `index.js`/`index.d.ts` are generated by that build and committed, so re-run `pnpm build` whenever you change the napi exports.
- **Git hooks**: `prepare: husky` installs the pre-commit hook (husky v9 layout — a plain shell script in `.husky/`, no deprecated v4 `husky.hooks` field). The hook runs `lint-staged`: oxlint --fix + prettier --write on staged JS/TS, prettier on md/json/yml, taplo on toml. Note `pnpm install` must have run at least once for `prepare` to fire; `git commit --no-verify` bypasses it when needed.
